# \# Hotel Booking Cancellation Prediction System

# 

# \## Introduction

# 

# This project is a web application that predicts whether a hotel booking will be canceled using a Machine Learning model.

# 

# The system consists of:

# 

# \- \*\*Backend:\*\* FastAPI

# \- \*\*Frontend:\*\* ReactJS

# \- \*\*Machine Learning:\*\* Scikit-learn

# 

# \---

# 

# \## Project Structure

# 

# ```

# web/

# │

# ├── back\_end/          # FastAPI backend

# ├── front\_end/         # React frontend

# ├── requirements.txt   # Python dependencies

# └── README.md

# ```

# 

# \---

# 

# \## Prerequisites

# 

# Before running the project, make sure the following software is installed:

# 

# \- Python 3.10 or later

# \- Node.js (v18 or later recommended)

# \- npm

# 

# \---

# 

# \## 1. Install Python Dependencies

# 

# From the \*\*web\*\* directory, run:

# 

# ```bash

# python3 -m pip install -r requirements.txt

# ```

# 

# \---

# 

# \## 2. Start the Backend

# 

# Open \*\*Terminal 1\*\*.

# 

# Navigate to the backend directory:

# 

# ```bash

# cd back\_end

# ```

# 

# Start the FastAPI server:

# 

# ```bash

# python3 -m uvicorn main:app --reload

# ```

# 

# The backend will be available at:

# 

# ```

# http://127.0.0.1:8000

# ```

# 

# \---

# 

# \## 3. Start the Frontend

# 

# Open \*\*Terminal 2\*\*.

# 

# Navigate to the frontend directory:

# 

# ```bash

# cd front\_end

# ```

# 

# Install the required Node.js packages:

# 

# ```bash

# npm install

# ```

# 

# Start the React application:

# 

# ```bash

# npm start

# ```

# 

# The frontend will be available at:

# 

# ```

# http://localhost:3000

# ```

# 

# \---

# 

# \## Running the Project

# 

# The project requires \*\*both services\*\* to be running simultaneously.

# 

# | Terminal | Command |

# |----------|---------|

# | Terminal 1 | `cd back\_end`<br>`python3 -m uvicorn main:app --reload` |

# | Terminal 2 | `cd front\_end`<br>`npm install` \*(first run only)\*<br>`npm start` |
